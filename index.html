Inserisci un URL e clicca "Carica Pasti" per iniziare.

Formato CSV Richiesto

Per essere compatibile, il tuo file CSV deve rispettare le seguenti regole:

  1. Usare il carattere Tabulatore (`\t`) come separatore di colonna.
  2. Avere la seguente intestazione (header) nella prima riga:
    id nomePasto tipoPasto ingredienti etichette

Dettaglio Colonne:

  • id: Un numero progressivo unico per ogni pasto.
  • nomePasto: Il nome visualizzato nell'app (es. Pranzo: Riso + Tonno).
  • tipoPasto: Il tipo di pasto (es. Pranzo, Cena).
  • ingredienti: Descrizione degli ingredienti (es. "Riso: 80g, Tonno: 112g").
  • etichette: Tag separati da virgola, senza spazi (es. contiene-soia,vegetale).

Esempio Completo:

id	nomePasto	tipoPasto	ingredienti	etichette
                1	Pranzo: Riso + Tonno	Pranzo	"Riso Basmati: 80g (s), Tonno: 112g (sg)"	pesce
                2	Pranzo: Piadina + Tofu	Pranzo	"Piadina Integrale: 80g, Tofu: 125g"	contiene-soia,vegetale
                3	Cena: Bistecca di Soia	Cena	"Soia Testurizzata: 70g (s), Pane: 40g"	contiene-soia,vegetale
