Formato CSV Richiesto

Il file deve usare il Tabulatore come separatore e avere questa intestazione:

id	nomePasto	tipoPasto	ingredienti	etichette

Esempio:

              
                        id nomePasto  tipoPasto ingrediente etichette

                        2  Pranzo: Piadina+Tofu Pranzo    "Piadina: 80g, Tofu: 125g"    contiene-soia,vegetale
                        3  Cena: B. di Soia     Cena      "Soia: 70g, Pane: 40g"        contiene-soia,vegetale
