📚 Libreria Pasti

Carica una configurazione per iniziare.

Formato `config.json` Richiesto

Il file deve essere un JSON con due chiavi principali: rules e meals.

Esempio da copiare:

{
"rules": [
  {
    "tag": "contiene-soia",
    "type": "daily-block",
    "limit": 1,
    "message": "Non puoi consumare più di un pasto con soia al giorno."
  }
],
"meals": [
  {
    "id": "1",
    "nomePasto": "Pranzo: Riso+Tonno",
    "tipoPasto": "Pranzo",
    "ingredienti": "Riso: 80g, Tonno: 112g",
    "etichette": ["pesce"]
  },
  {
    "id": "2",
    "nomePasto": "Cena: B. di Soia",
    "tipoPasto": "Cena",
    "ingredienti": "Soia: 70g, Pane: 40g",
    "etichette": ["contiene-soia", "vegetale"]
  }
]
}
