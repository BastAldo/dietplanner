# Funzionalità: NutriPlan v1.6

## 1. Visione Generale
Una web app frontend-only, responsiva e con tema scuro, per creare e gestire piani alimentari flessibili con conteggio calorico giornaliero. Tutti i testi dell'interfaccia sono gestiti centralmente per una facile manutenzione.

## 2. User Stories
* **US-1 (Caricamento Dati):** L'utente può caricare una configurazione da un file JSON remoto.
* **US-2 (Visualizzazione Calendario):** L'utente vede un calendario come interfaccia principale.
* **US-3 (Pianificazione via Modale):** L'utente clicca su uno slot vuoto per aprire un modale e selezionare un pasto.
* **US-11 (Cancellazione Pasti):** L'utente può rimuovere un pasto inserito.
* **US-15 (Layout Mobile Leggibile):** Su mobile, il calendario è una lista scorrevole orizzontalmente.
* **US-16 (Conteggio Calorie):** L'utente vede il totale calorico (min-max) per ogni giorno.
